# tau2-loop

A policy-following customer-support agent for [τ²-bench](https://github.com/sierra-research/tau2-bench)
(airline first), with a scored, versioned, self-improving optimisation loop — the same
mechanics as [DABStep-loop](https://github.com/nmp-dsci/DABStep-loop).

Status: **discovery and plan** — see `.lavish/s00_tau2-loop-init-plan.html` for the
benchmark discovery (domains, splits, scoring, judge, cost) and the build plan.
No agent, runs or scores exist yet.
